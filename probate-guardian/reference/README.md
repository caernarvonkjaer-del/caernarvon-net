# Reference documents

This folder contains the external and historical documents used to verify
Probate Guardian's filing language, court-workbook behavior, and local review
practice. It is intentionally visible from the repository root.

- `legal/statutes/` — Florida statutes and court-rule references: Chapter 744,
  the Florida Probate Rules, and the Florida Rules of General Practice and
  Judicial Administration (the Florida Bar's July 1, 2026 compilation, from
  `https://www-media.floridabar.org/uploads/2026/08/2027_01-JULY-Florida-Rules-of-General-Practice-and-Judicial-Administration-7-1-2026.pdf`,
  downloaded 2026-09-29; Probate Rule 5.041 sends service to its Rule 2.516).
  `MILESTONE-71-PROPOSAL.md` relies on the last one for Rules 2.515 and 2.516.
- `legal/administrative-orders/` — circuit administrative orders.
- `legal/workslips/` — Clerk guardianship workslips and review sheets.
- `plan-forms/` — original plan-form PDFs and extracted text used for comparison.

These files are evidence and reference material, not application runtime input.
When a source is added, moved, renamed, or removed, update [`../file_index.md`](../file_index.md)
and record any code or proposal path that depends on it.

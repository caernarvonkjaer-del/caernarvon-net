Probate Guardian — Web App (v1.5.30)
=====================================

QUICK START
===========

EASIEST WAY TO RUN IT (no install, works from a thumb drive):
1. Unzip ProbateGuardian-web-v1.5.30.zip into any folder (or straight onto
   a USB drive).
2. Double-click index.html. Use Chrome or Edge (Firefox's support for
   this is inconsistent — test it once before relying on it there).
That's it — no terminal, no Node.js, nothing else to install.

ALTERNATIVE (if you prefer running it through a local server):
1. Unzip into any folder.
2. Open a terminal.
3. Navigate to the unzipped folder:  cd path/to/unzipped/folder
4. Run:  npx http-server . -p 8420 -c-1
5. Open http://localhost:8420 in Chrome or Edge.

IMPORTANT SECURITY NOTES
========================
- Do NOT open via a network IP address (e.g. 192.168.x.x) or remote URL.
  Only open the file directly from disk or via localhost.
  The app requires "secure context" to encrypt your data.
- If using file:// directly, Chrome and Edge work fine. Firefox may have
  limitations with IndexedDB, so test it first before relying on it.
- Your master password cannot be reset. If you forget it, your data cannot
  be recovered. Keep your password safe or use "No Password" mode.


DETAILED SETUP FOR DIFFERENT OPERATING SYSTEMS
===============================================

WINDOWS:
1. Download the .zip file.
2. Right-click → Extract All → Choose destination.
3. Open the folder and double-click index.html.
4. If you get a Windows Defender warning, click "More info" → "Run anyway".
   (The file is safe; this is just Windows being cautious about downloaded files.)

MAC:
1. Download the .zip file.
2. Double-click to auto-extract (or use Archive Utility).
3. Open the folder and double-click index.html.
4. If you get a "can't open" dialog, right-click → Open With → Chrome or Safari.
   (Macs block unsigned downloads by default.)

LINUX:
1. Unzip the file: unzip ProbateGuardian-web-v1.5.30.zip
2. Open index.html with Chrome: google-chrome path/to/index.html
3. Or run a local server: cd path/to/folder && python3 -m http.server 8000
   Then open http://localhost:8000 in your browser.


FIRST-TIME SETUP
================

On your very first launch:
1. Choose your data protection level. This CANNOT be changed later without
   starting over:

   ○ "No Password / No Encryption"
     - App opens immediately, no password ever needed
     - All data stored as plain readable text on your computer
     - Anyone with access to your device can read case data
     - Faster but not secure for sensitive information

   ○ "Encrypted & Password Protected"
     - Master password required every time you open the app
     - All case data is encrypted (AES-256) on your computer
     - If you forget the password, data cannot be recovered
     - Best for sensitive guardianship cases

2. If using encryption, create a strong master password (8+ characters).
   Write it down and store it safely.

3. Click "+ Add Ward" to create your first guardianship case.

4. Choose an inventory type:

   📋 Guardian Inventory (Initial Inventory)
      - Complete assets as of guardianship inception date
      - Most detailed form, covers all asset types
      - Includes Parts I-VI (attestations & filings)
      - For initial filing when guardianship begins

   📊 Simplified Annual Accounting
      - Simple income/expenses summary only
      - Only available for guardianships UNDER $1M
      - Limited transactions (interest, settlements, taxes)
      - Quicker to complete if you qualify

   📈 Annual Accounting
      - Full year-by-year accounting with detailed schedules
      - For ongoing guardianships (after initial inventory)
      - Includes income, expenses, assets, and reconciliation
      - Most comprehensive option

   🛡 Simplified Annual Plan
      - Reports on the ward as a PERSON, not their money
      - Where they lived, their medical care, diagnosis, social life,
        and whether any rights should be restored
      - A separate court filing from the accountings above
      - If you are guardian of both person and property, you file a Plan
        AND an Accounting; create one record for each, give them the same
        case number, and use the dashboard's "Grouped by Case" view

5. Enter the ward's name and click "Create Ward".

6. IMMEDIATELY save a backup:
   - Click "Save Data File (.sav)" in the sidebar
   - Save it to a safe location (NOT on the computer it's running on)
   - This is your insurance policy. Store it securely.


FILLING IN YOUR FORMS
=====================

Understanding Your Inventory Type

GUARDIAN INVENTORY (Initial):
- Work through Schedules A-1 → A-2 → B-1 → B-2 → B-3 → B-4 → C-1 → C-2 → C-3 → C-4 → C-5
- Then complete Parts III-VI (Signatures & Attestations)
- Each schedule shows: ✓ (complete), ⚠ (incomplete), or nothing (not started)
- Schedule indicators help you track progress

SIMPLIFIED ANNUAL ACCOUNTING:
- Start with Part I (cover page information)
- Fill Part II (income/expenses summary)
- Part III (signatures) last
- Much faster than full accounting if you qualify

ANNUAL ACCOUNTING:
- Start with Part II (Guardian Certification)
- Add guardian signatures in Part III
- Fill asset schedules as needed (no required order)
- Reconciliation happens automatically

Common Fields You'll Encounter

Ward's %: The percentage of an asset that belongs to the ward. Enter as plain
         numbers (50, not 0.50). Example: if ward owns 50% of a house, enter 50.

Restricted: Assets that cannot be sold without court permission. Usually real
           estate that must go through court approval process. Mark "Yes" only
           if court order restricts use.

Carrying Value: The depreciated/adjusted value for accounting. May differ from
               current market value. Use book value, not sales price.

Personal Residence: The main home where the ward lives. Mark "Yes" only for
                   the primary residence, not investment properties.

Income Property: Property held for income (rental, lease). Mark "Yes" if the
                property generates rents or other returns.

Depository: The bank or institution holding ward's money. For Simplified
           Accounting, ALL money must be in a court-designated depository.

SSN/EIN: Social Security Number (individuals) or Employer ID (businesses/trusts).
        Required for most court filings.

Signature Date: Must be within the accounting period or filing deadline.

Hover over any "?" icon for instant field explanations.


SAVING AND BACKING UP YOUR DATA
================================

How Auto-Save Works:
- In Chrome and Edge, once you've saved a .sav file once, later changes are
  written back to that same file automatically as you work — no further
  action needed
- Firefox and Safari cannot write to your .sav file silently in the
  background. On those browsers a reminder to save manually pops up every
  15 minutes whenever there are unsaved changes
- Sidebar shows: "Last backup: X minutes ago" or "Unsaved changes"
- You can change Auto-Save frequency: 5 min / 10 min / 30 min / Off (Chrome/Edge only)
- If a tab is closed or crashes before you ever save a .sav file, reopening
  the app in the SAME browser may offer to restore that unsaved work from a
  temporary local cache. This is a short-term safety net, not a backup — it
  disappears once you save (or decline the offer), and it never leaves your
  device

Creating Backups (CRITICAL):
1. Click "Save Data File (.sav)" in the sidebar
2. Choose a location OUTSIDE this folder (external drive, cloud sync, email)
3. The .sav file contains all your wards, encrypted if you set a password
4. Store multiple copies in different locations

Restoring from Backup:
1. Click "Open Data File (.sav)"
2. Choose your .sav backup file
3. All wards and data are restored immediately

Emergency Recovery:
- The temporary local cache described above only survives a crash or an
  accidentally closed tab in the SAME browser on the SAME device, and only
  until the app is next opened there — it is not a substitute for a .sav backup
- If your device fails or the file is lost, you can only restore from backups
- If you lose all backups AND forget your password, the data is gone forever
- Always keep at least 2 copies in different locations


EXPORTING FOR FILING
====================

When ready to file with the court:

1. Click "📄 Print Preview" at the bottom of the sidebar
2. Review your forms for errors (fields marked in red are incomplete)
3. Check your court's requirements:
   - Some courts want PDF (use "Export as PDF")
   - Some want Excel (use "Export as Excel")
4. "Export as Excel" fills in the official blank Clerk of Court workbook.
   A blank copy is included with the app for the Initial Inventory, the
   Simplified Accounting and the Annual Accounting, so there is nothing to
   import first — just click "Export as Excel".
5. If your court uses its own version of the form:
   - Use the "📥 Import Excel File" button to upload their blank workbook
   - The app remembers it and uses it for every later export
   - App fills it with your data
   - Export and submit

Tips:
- Always review Print Preview before exporting—catch errors there
- PDF is best for most filings (easier to read)
- Keep a PDF copy for your records
- Export early and often (don't wait until the last moment)


TROUBLESHOOTING
===============

"App shows 'Loading...' and doesn't proceed"
→ You probably have another tab open with Probate Guardian running.
  Close all other tabs and reload this one.

"Password incorrect — please try again"
→ Check your caps lock
→ If you forget your password, the data cannot be recovered
→ You'll need to clear all data and start over

"Changes aren't saving"
→ Check sidebar for status. If it says "needs one manual save first",
  click "Save Data File (.sav)" once to activate auto-save.
→ Make sure you have space on your hard drive (a full disk stops saves)
→ Try closing other browser tabs

"Form fields are too small / hard to read"
→ Zoom in: Ctrl+Plus (Windows) or Cmd+Plus (Mac)
→ Zoom out: Ctrl+Minus or Cmd+Minus
→ These are browser zoom controls, not app settings

"Export to Excel/PDF doesn't work"
→ Check Print Preview for red validation errors (required fields)
→ If fields show validation errors, fill them in first
→ Try a different browser (Chrome and Edge work best)

"I lost my backup file and can't remember my password"
→ Unfortunately, your data cannot be recovered. The password cannot be reset.
→ Clear all data (⚠ this is permanent) and start fresh
→ Or use "No Password" mode (also starting fresh)

"The app looks different than before"
→ Updates happen automatically when you reload
→ If something changed unexpectedly, check the version number
→ Try clearing your browser cache: Ctrl+Shift+Delete


FREQUENTLY ASKED QUESTIONS
==========================

Q: Can I use this app on multiple computers?
A: Yes. Save your data file (.sav) and open it on any computer. The data
   travels with you. You can also email the .sav to yourself.

Q: What if I'm using a Chromebook?
A: This works great on Chromebooks! Double-click the index.html file or
   run it via a local server. Encryption and backup work normally.

Q: Can I share this app with other guardians?
A: Yes, but each guardian should use their own master password. Do NOT
   share passwords. Each person should keep their own backup.

Q: Do I have to import the court's Excel template before exporting?
A: No. A blank copy of the official workbook ships with the app for all
   three filing types, so "Export as Excel" works straight away.

Q: What if my court requires its own version of the Excel template?
A: Use the "Import Excel File" button to upload their blank workbook. The
   app remembers it, fills it with your data and exports it back to them.

Q: Can I merge two wards' data?
A: Not directly. You'll need to manually re-enter data or copy values between
   wards. Plan to do this carefully to avoid errors.

Q: How long can I keep working on the same ward?
A: As long as you want. There's no time limit. Auto-save keeps your work safe.

Q: What happens if I close the browser/computer?
A: Your data only lives in memory and in whatever .sav file you've saved —
   it is not stored anywhere else automatically. In Chrome/Edge, once you've
   saved a .sav file once, later changes keep writing back to that file, so
   reopening it picks up where you left off. If you close or crash before
   ever saving, the app may offer to recover the unsaved work from a
   temporary local cache the next time you open it in the same browser — but
   that's a short-term safety net, not a substitute for saving a .sav backup
   yourself.

Q: Do I need an internet connection?
A: No. This app works 100% offline. No data ever leaves your computer.

Q: Is my data really encrypted?
A: Yes, if you choose "Encrypted & Password Protected". All data is encrypted
   with AES-256 encryption before it's stored on your computer.

Q: Can you recover my data if something goes wrong?
A: Only if you have a backup (.sav file). There are no cloud backups or
   recovery options. Backups are YOUR responsibility.

Q: What if I want to stop using the app?
A: Export all your forms as PDF and keep them. Your .sav file is your backup
   forever. You can reopen the app anytime to access that .sav file.

SECURITY & PRIVACY
==================

Data Location:
- Your data is stored on YOUR computer only (not the cloud)
- The .sav file you save is the durable copy; the browser also keeps a
  short-lived, encrypted local cache of unsaved changes purely for crash
  recovery, cleared automatically as soon as you save a .sav file
- No data is ever sent to servers or the internet
- This is more private than online applications

Encryption:
- If you choose "Encrypted & Password Protected", data is encrypted with
  AES-256 (same as banks use)
- Only your master password unlocks it
- Even if someone has physical access to your computer, they can't read
  encrypted data without the password

Password Security:
- Create a strong password (8+ characters, mix of letters/numbers)
- Write it down and store safely (not on the computer)
- If you forget it, data cannot be recovered
- There is NO password reset option

Sharing:
- Do NOT share your master password
- Each person should use their own .sav backup
- If you need to share a case with an attorney, export the PDF and email it
